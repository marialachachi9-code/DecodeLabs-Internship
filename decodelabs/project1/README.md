# Cook Good — Recipe Landing Page

A static landing page for a home-cooking recipe brand, built as Project 1 of the DecodeLabs Frontend Development internship track.

## Overview

This project focuses on structural fundamentals: semantic HTML, external CSS, and layout systems (Grid + Flexbox) — no JavaScript involved. The goal was to build a clean, accessible, single-page site using proper markup and styling practices rather than complex interactivity.

## Sections

- **Header** — Logo and navigation, built with Flexbox
- **Hero** — Full-height intro with headline, tagline, and call-to-action button
- **Recipe Grid** — A 12-column CSS Grid layout showcasing recipe cards (image, name, time/difficulty tag)
- **Footer** — Brand info, navigation links, and contact details

## Tech Used

- HTML5 (semantic elements: `header`, `nav`, `main`, `section`, `footer`)
- CSS3 (Grid for macro layout, Flexbox for component alignment)
- No frameworks or JavaScript

## Key Practices Followed

- One `<h1>` per page, no skipped heading levels
- External stylesheet only — no inline styles or ID-based styling
- DRY CSS with reusable classes
- Images with `alt` text and explicit `width`/`height` to prevent layout shift
- Responsive units (`%`, `max-width`) instead of fixed pixel widths
- `box-sizing: border-box` applied globally

## How to Run

Clone the repo and open `index.html` in a browser, or use a Live Server extension for auto-reload during development.
